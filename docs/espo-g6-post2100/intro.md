# Introduction

ESPO-G6-post2100 is a small ensemble of bias-adjusted CMIP6 simulations covering the period 1950–2300. It fills a gap in the climate service toolbox where user-ready ensembles typically cover the 21st century only. In the next section, you'll find a user guide describing the dataset and highlighting issues to be aware of when analyzing it.
